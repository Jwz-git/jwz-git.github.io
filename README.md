## Editing and deployment

Edit `index.html` to update the page. It is a standalone static HTML file with no build dependencies or external fonts. Keep the visible profile and structured data in sync when changing personal details.

GitHub Pages publishes from the root of the `main` branch. Push a commit to `main` to update the site. `.nojekyll` disables Jekyll processing.

To preview locally:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open http://127.0.0.1:8000/.
